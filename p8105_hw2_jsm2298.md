## Load and Clean NYC transit data: retain line, station, name, station latitude / longitude, routes served, entry, vending, entrance type, and ADA compliance. Convert the entry variable from character (YES vs NO) to a logical variable (case_match function may be useful).

nyc_t_df <- read_csv("data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv") |>

mci_amyloid_df = read_csv("data/data_mci/mci_amyloid.csv", skip = 1, na = c("Na", "NA")) |>

This dataset had similar cleaning steps to the baseline data set. We had
to load the data with read_csv, skip the first line, and then filter out
NA values coded as “Na”. Then we cleaned the names of the columns. I
decided to pivot the data into long form to make it tidy by creating two
columns, one to represent the time point (previously encoded in the
column title), and another to represnt the amyloid ratio at a given
time. I then used case_when to recode the time variable as numeric to
represent the years since baseline. I also re-coded the amyloid ratio as
numeric rather than categorical. Now the dataset has only three columns,
one represnting the subject ID, and another representing the year of
amyloid measurement since baseline. The alst column represents the
amyloid ratio.
