# Question 1:

## Load and Clean NYC transit data: retain line, station, name, station latitude / longitude, routes served, entry, vending, entrance type, and ADA compliance. Convert the entry variable from character (YES vs NO) to a logical variable (case_match function may be useful).

``` r
nyc_t_df <- read_csv("data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv") |> 
  janitor::clean_names() |> 
  select(line, station_name, station_latitude, station_longitude, contains("route"), entry, vending, entrance_type, ada) |> 
  mutate(entry = case_when(
    entry == "YES" ~ TRUE,
    TRUE ~ FALSE
  ),
  vending = case_when(
    vending == "YES" ~ TRUE,
    TRUE ~ FALSE
  )) |> 
  pivot_longer(cols = contains("route"),
               names_to = "route_number",
               values_to = "route_name",
               values_transform = list(route_name = as.character))
```

## Write a short paragraph about this dataset – explain briefly what variables the dataset contains, describe your data cleaning steps so far, and give the dimension (rows x columns) of the resulting dataset. Are these data tidy?

The dataset contains information about nyc subway lines. Specifically,
one row of the original data set corresponds to one exit in a given
station. The line and station name correspond to the specific station on
a given line. The route# columns show which trains travel to a given
station. The latitude and longitude columns show the specific location
of each exit / entrance. We also have other variables such as entrance
type and entry yes vs no, which give details about entrance to each
station. I did a lot of cleaning with the data to remove unnecessary
columns and also pivot the data into long form so that the route number
and route name each take up one column instead of having a column for
each route number. After this changem the data are tidy, but the
original data was not tidy.

### What proportion of station entrances / exits without vending allow entrance?

``` r
nyc_prop_vec = nyc_t_df |> 
  filter(vending == FALSE) |> 
  select(line, station_name, station_longitude, station_latitude, entry) |> 
  unique() |> 
  group_by(entry) |> 
  summarize(n = n()) |> 
  pull(n)

nyc_prop = nyc_prop_vec[2] / (nyc_prop_vec[2] + nyc_prop_vec[1])

paste0(nyc_prop, " is the proportion of station entrances / exits without vending that allow entrance.")
```
